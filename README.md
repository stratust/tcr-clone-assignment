# TCR Clone Assignment

An R pipeline for assigning TCR (T Cell Receptor) clonotypes from **Cell Ranger VDJ** output (10x Genomics), with proper handling of dual α/β chains per cell barcode.

---

## Biological Background

### V(D)J Recombination and TCR Diversity

T cell receptors (TCRs) are heterodimeric proteins composed of an α (alpha) chain and a β (beta) chain, each generated by V(D)J recombination during thymic development. Each mature T cell carries, in theory, **one functional α chain and one functional β chain**, which together determine its antigen specificity.

### The Dual-Chain Problem

In single-cell VDJ sequencing, we frequently observe **more than one productive α and/or β chain** for the same cell barcode. This can arise from two causes:

#### 1. Allelic Inclusion (True Biological Phenotype)

During thymic selection, the **TCRα locus** rearranges on both chromosomes. Unlike TCRβ — which undergoes rigorous allelic exclusion — TCRα frequently escapes negative feedback before one allele is silenced. The result:

- **~25-35% of mature T cells** carry **two productive α chains** (dual-TCRα)
- **~3%** carry **two productive β chains** (dual-TCRβ, rare — α:β ratio ≈ 10:1)

These dual-TCR cells are biologically relevant: they may have altered antigen affinity, participate in cross-reactivity, and have been implicated in autoimmunity and tolerance.

**References (verified via PubMed):**
- Arstila et al. (1999) *Science* 286:958-961 — foundational estimate of human TCRαβ diversity
- Tuovinen, Salminen & Arstila (2006) *Blood* 108:1601 (PMID: 16926292) — 10-30% of mature T cells express two TCR chains
- Dupic et al. (2019) *PLoS Comput Biol* 15(3):e1006874 (PMID: 30830899) — quantitative model: ~35% of cells express both α chains
- Schuldt et al. (2015) *J Immunol* (PMID: 26693713) — dual-TCRα outnumbers dual-TCRβ by ~10:1
- Schuldt et al. (2017) *J Immunol* 199(1):33-38 (PMID: 28539428) — dual-TCRα as autoimmune hazard via impaired Treg generation
- Schuldt & Binstadt (2019) *Front Immunol* (PMID: 30670579) — comprehensive review on dual-TCR biology

#### 2. Technical Artifacts

| Artifact | Cause | Diagnosis |
|----------|-------|-----------|
| **Doublets/multiplets** | 2+ cells captured in the same GEM (gel bead-in-emulsion) | High dual-α rate (>50%) |
| **Ambient RNA** | Cell-free mRNA contaminating the barcode | Secondary chain with very low UMI |
| **Index hopping** | Index swapping during sequencing | Random pattern, not reproducible |

### Distinguishing Biology from Artifact

This pipeline uses three criteria to classify dual-TCR cells as **trusted** vs. **artifact**:

1. **UMI ratio**: the secondary chain must have ≥10% of the primary chain's UMI (adjustable)
2. **Absolute UMI**: the secondary chain must have ≥5 UMIs (adjustable)
3. **Expected frequency**: if >50% of cells have dual-α, this indicates doublet contamination

## The Pipeline

### Overview

```
all_contig_annotations.csv (Cell Ranger VDJ output)
         │
         ▼
   ┌─────────────────┐
   │  1. Filtering    │  productive + high_confidence + is_cell + TRA/TRB
   └────────┬────────┘
            ▼
   ┌─────────────────┐
   │  2. Ranking      │  For each barcode, rank chains by UMI
   │     by UMI       │  (primary vs. secondary)
   └────────┬────────┘
            ▼
   ┌─────────────────┐
   │  3. Dual-TCR     │  Filter secondary chains by quality
   │     filtering    │  (UMI ratio ≥ 10% + absolute UMI ≥ 5)
   └────────┬────────┘
            ▼
   ┌─────────────────┐
   │  4. Clone        │  Define clones by CDR3 (TRB or TRA+TRB)
   │     assignment   │  Assign clone IDs ordered by frequency
   └────────┬────────┘
            ▼
   ┌─────────────────┐
   │  5. QC + Plots   │  Shannon diversity, Pielou evenness,
   │                  │  clone size distribution, dual-TCR rates
   └─────────────────┘
```

### Clone Definition

The pipeline supports three clone definition modes:

| Mode | Description | Recommended Use |
|------|-------------|-----------------|
| `TRB` *(default)* | Clone = TRB CDR3 aa + V gene + J gene | Standard in the field; TRB is the primary determinant of specificity |
| `TRA_TRB` | Clone = TRA CDR3 + TRB CDR3 combination | More stringent; useful when TRB alone is not discriminating |
| `TRB_cdr3_only` | Clone = TRB CDR3 aa only | Most permissive; for exploratory analysis |

### Main Functions

| Function | Description |
|----------|-------------|
| `load_contigs()` | Loads and filters `all_contig_annotations.csv` (single sample) |
| `load_contigs_batch()` | Loads and combines multiple samples with unique barcodes |
| `assign_clones()` | Core function — returns only the dataframe with clone IDs |
| `rank_chains()` | Ranks chains by UMI for each barcode |
| `filter_dual_tcr()` | Filters dual-TCR cells by quality criteria |
| `build_clones()` | Builds clone table and assigns clone IDs |
| `qc_summary()` | QC metrics: dual-TCR rate, Shannon diversity, Pielou |
| `to_screpertoire()` | Formats contigs for `scRepertoire` integration |
| `run_tcr_pipeline()` | Runs the full pipeline (single sample) |
| `run_tcr_pipeline_batch()` | Runs the full pipeline (multiple samples combined) |

### QC Metrics

- **Dual-α rate**: % of cells with 2+ productive α chains (expected: 25-35%)
- **Dual-β rate**: % of cells with 2+ productive β chains (expected: ~3%)
- **Shannon diversity index**: $H' = -\sum p_i \ln(p_i)$
- **Pielou evenness**: $J' = H' / \ln(S)$, where S = number of clones
- **Top 10 clone share**: % of cells belonging to the 10 largest clones
- **Singleton rate**: % of clones with only 1 cell

## Usage

### Programmatic Use (dataframe only)

If you just want the dataframe with clone assignments — no files written, no plots generated — use `assign_clones()`:

```r
source("tcr_clone_assignment.R")

# Single sample
contigs <- load_contigs("vdj_t/outs/all_contig_annotations.csv")
clones_df <- assign_clones(contigs, clone_def = "TRB")

# head(clones_df)
# # barcode | clone_id | n | cdr3_prim_TRB | v_gene_prim_TRB | ...

# Multiple samples — barcodes are prefixed with the sample name
# from the list names to prevent collisions across samples
# (10x barcodes come from a shared ~3.4M whitelist — the same sequence
# in different runs = different physical cells)
contigs <- load_contigs_batch(list(
  CTRL    = "ctrl/vdj_t/outs/all_contig_annotations.csv",
  PATIENT = "patient/vdj_t/outs/all_contig_annotations.csv"
))
clones_df <- assign_clones(contigs, clone_def = "TRB")

# The list names become the barcode prefix and the sample column:
# "CTRL"    → barcode = "CTRL_AAACCTGAGAAACCGC-1",    sample = "CTRL"
# "PATIENT" → barcode = "PATIENT_AAACCTGAGAAACCGC-1", sample = "PATIENT"
```

| Function | Writes files? | Generates plots? | Returns |
|----------|---------------|------------------|---------|
| `assign_clones()` | ❌ | ❌ | `data.frame` with clone_id |
| `run_tcr_pipeline()` | ✅ CSVs + PDFs | ✅ | Full `list` |
| `run_tcr_pipeline_batch()` | ✅ CSVs + PDFs | ✅ | `list` + per-sample + overlap |

### Full Pipeline (single sample)

```r
source("tcr_clone_assignment.R")

results <- run_tcr_pipeline(
  all_contig_csv = "vdj_t/outs/all_contig_annotations.csv",
  output_dir     = "tcr_results",
  clone_def      = "TRB",     # "TRB", "TRA_TRB", or "TRB_cdr3_only"
  min_umi        = 5,         # minimum UMI per contig
  min_read       = 20,        # minimum reads per contig
  min_ratio      = 0.1,       # secondary chain ≥ 10% of primary UMI
  min_abs_umi    = 5,         # secondary chain ≥ 5 absolute UMIs
  make_plots     = TRUE
)
```

### Full Pipeline (batch — multiple samples combined)

```r
samples <- list(
  CTRL    = "ctrl/vdj_t/outs/all_contig_annotations.csv",
  PATIENT = "patient/vdj_t/outs/all_contig_annotations.csv"
)

results <- run_tcr_pipeline_batch(
  sample_list = samples,
  output_dir  = "tcr_results_batch",
  clone_def   = "TRB"
)

# Additional batch outputs:
# - per_sample_summary.csv     (per-sample cell counts and clone stats)
# - cross_sample_overlap.csv    (clonotypes shared across 2+ samples)
# - batch_cells_per_sample.pdf
# - batch_clonotypes_per_sample.pdf
# - batch_top_clone_expansion.pdf
```

## Adjustable Parameters

| Parameter | Default | Description | When to Adjust |
|-----------|---------|-------------|----------------|
| `clone_def` | `"TRB"` | Clone definition | `"TRA_TRB"` for more stringency; `"TRB_cdr3_only"` for exploration |
| `min_umi` | `5` | Minimum UMI per contig | Lower (3) for low-input libraries; raise (10) for high-complexity |
| `min_read` | `20` | Minimum reads per contig | Lower (10) if shallow sequencing; raise (50) for extra stringency |
| `min_ratio` | `0.1` | Minimum UMI ratio (sec/prim) | `0.05` to capture more dual-TCRs; `0.2` for more stringency |
| `min_abs_umi` | `5` | Minimum absolute UMI on secondary chain | Increase to reduce false positives |

## Input Structure

The pipeline expects the `all_contig_annotations.csv` file produced by Cell Ranger VDJ, with the following key columns:

| Column | Description |
|--------|-------------|
| `barcode` | Cell barcode |
| `is_cell` | Whether the contig was assigned to a cell (vs. background) |
| `high_confidence` | Assembly confidence of the contig |
| `chain` | Chain type (TRA, TRB, TRG, TRD, IGH, IGL, IGK) |
| `v_gene`, `d_gene`, `j_gene`, `c_gene` | V(D)J and constant genes |
| `cdr3` | CDR3 amino acid sequence |
| `cdr3_nt` | CDR3 nucleotide sequence |
| `productive` | Whether the rearrangement is productive (in-frame, no stop codon) |
| `umis` / `umi_count` | Number of UMIs |
| `reads` / `read_count` | Number of reads |
